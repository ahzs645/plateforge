# AA bilingual 2002 source-specific lettering

Source: [WorldLicensePlates Iran](http://www.worldlicenseplates.com/world/AS_IRAN.html), collector sheet `AS_IRAN_OT2.jpg`, original sheet crop `[323,141,581,242]`, resulting photograph **258 × 101 pixels**. Source date attribution is 2002–2003, not a capture date. Reuse permission is not established; private critical research only.

## Independent roles

- `source-bilingual-2002-persian`: main upper Persian digits; cap 25.6 px, baseline 40.3 px. Observed ۱۶۹; ۰۲۳۴۵۷۸ inferred.
- Same profile, role `allocation`: upper-left 111; cap 28.3 px, baseline 43 px. Only ۱ is observed here; all nine other digits are inferred specifically for this role.
- `source-bilingual-2002-latin`: broad, bold lower Latin digits; cap 24.9 px, baseline 85 px. Observed 1,6,9; 0,2,3,4,5,7,8 inferred.
- `source-bilingual-2002-code`: thin class-code A, cap 23.7 px, baseline 89.5 px. Only A is evidenced; repeated AA uses a 16.3 px advance.

Every outline is a manually authored Bézier/geometric drawing. No generic font was used to substitute the displayed numeric forms. Source wear, grain and blur are omitted. The original image is too small to establish certified production dies: observed means source-guided reconstruction, not an exact original master. Inferred digits are explicitly marked per glyph and carry construction rationale. They complete editable research alphabets without falsely expanding the source evidence. Inferred allocation digits use its observed one to establish proportion/weight, and explicitly inferred conventional numeral structure adapted from the main-role study; none is treated as observed in that block.

`sourceAdvance` is the shared-role advance in original source pixels, normalized once by the generator. Source cap/baseline are never individually re-fitted per glyph. Editable runs use stable per-character metrics; the audit overlay shows the slightly irregular actual source occurrences.

`source-geometry.json` records measured role ink rectangles and relative drawing fractions for the composition. `bilingual-full-digit-boards.svg` labels every digit as observed or inferred; `bilingual-source-overlay.svg` shows source, transparent overlay and cleaned source-placement comparison.
