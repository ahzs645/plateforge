# Vancouver Centennial and EXPO 86 souvenirs

The Centennial preset uses the user-supplied geometric artwork, including both outlined wordmarks, joined 100, mountains, skyline and water. Green 1886 and blue 1986 columns and the lower bands follow the BCpl8s photograph. Complete artwork is scaled uniformly; no letter or oval is squeezed.

The Universal Exchange retail souvenir uses the uploaded Frankfurter Std Regular for its fixed EXPO86 lettering, instead of the linked official event symbol. Other event-symbol presets and the Type 3 presentation plate are separate designs. Centennial year columns retain the lighter geometric legend construction; the supplied heavy font is confined to the EXPO86 wordmark. Only the required fixed characters are converted to paths; the OTF is not bundled and unsupported characters do not fall back to invented forms. Both export and preview use the same outlined scene.

Asset hashes and attribution are in provenance.json. The vector kit describes a new geometric reconstruction and a visual Frankfurter identification, not an authenticated original master. Original font licensing/printing specifications are not provided by the attachments. Font metadata retains ITC copyright attribution. Artwork colours, shell details and placement remain approximate. The supplied Frankfurter Regular has heavier strokes and smaller round counters than the photographed EXPO86 lettering; those residuals are visible rather than hidden by distorting the font.

Validation: 1,609 tests passed across 45 files on the public deployment branch; the focused final checks passed 8 tests. The production build uses BASE_PATH=/plateforge/. Browser verification checks both routes, mobile layout, artwork clipping, six filled Frankfurter glyphs and standalone SVG downloads.

The [six-character photographic test](font-comparison.md) compares the uploaded Regular directly with the official live Medium specimen and width-only Regular variants. Medium wins all six comparisons and 54 paint-threshold trials. The interactive report is published at [EXPO86 font comparison](https://projects.ahmadjalil.com/plateforge/bc-font-comparisons/expo86/). The plate font itself remains unchanged by this evidence update.
