# Vancouver Centennial and EXPO 86 souvenirs

The Centennial preset uses the user-supplied geometric artwork, including both outlined wordmarks, joined 100, mountains, skyline and water. Green 1886 and blue 1986 columns and the lower bands follow the BCpl8s photograph. Complete artwork is scaled uniformly; no letter or oval is squeezed.

The Universal Exchange retail souvenir uses Frankfurter Std Medium for its fixed EXPO86 wordmark. The six outlines are derived from the official browser preview, with native advances, counters, curves and overshoots preserved at cap height 100. No font software is bundled; unsupported characters have no invented fallback. Preview and SVG/PNG exports use the same vectors. The lettering is confined to this photographed retail design; other event symbols, stencilled lettering and presentation-plate serials retain their separate profiles.

The [six-character photographic test](font-comparison.md) compares the uploaded Regular, official Medium specimen and width-only Regular variants. Medium won all six comparisons and 54 paint-threshold trials. The [interactive comparison](https://projects.ahmadjalil.com/plateforge/bc-font-comparisons/expo86/) now defaults to the actual production outlines, with the earlier raster candidates still available. Overall wordmark size and position are adjusted to the near-frontal photograph; glyph widths are not individually distorted.

Asset hashes and attribution are in provenance.json and medium-wordmark-provenance.json. The vector kit is a new geometric reconstruction rather than an authenticated historical master. Medium is a tested visual match, not a documented identification of the original manufacturer's typography. ITC attribution is retained. Artwork colours, shell details, placement and physical printing specifications remain approximate.

Validation: all 1,611 tests across 45 files and the production build passed. Browser checks cover both souvenir routes, mobile layout, standalone SVG downloads and all six photographic overlays. The implemented vectors overlap the independent Medium raster specimens by 97.6–99.5% after equal-height registration; this verifies conversion, not historical attribution.
