# Alberta · Wild Rose Country

The supplied upload contains **ITC Avant Garde Gothic Std Medium**, not Pro. Its PostScript name is `ITCAvantGardeStd-Md`, OTF version 1.018; cap height is 740 of 1000 units. Inspection of the glyph set and every GSUB lookup found no alternate W, e, t or y. The `aalt` feature covers punctuation and superior/ordinal forms, not these letters. Merely enabling `aalt` would not reproduce the plate.

The shared fixed-word master uses the supplied native outlines for the other letters, including the open R and rectangular i dot. W/e/t/y are explicit reconstructions using the [original Avant Garde alternate specimen](https://www.e-daylight.jp/fonts/type/a/agg/avant-garde-gothic.jpg), the user's PWG-542 and CKZ-3449 photographs, and the three credited World License Plates references in the [artwork review](https://projects.ahmadjalil.com/plateforge/alberta-artwork-review/#slogan). W is built from left-leaning diagonals and upright stems; e rotates the supplied outline 45 degrees about its bowl centre; t keeps the supplied stem/bar dimensions but removes the left arm; y has an upright left branch and a continuous diagonal descender. These are **not extracted Pro alternates**.

Original outlines and native advances remain unchanged outside these four letters. Native GPOS pair positioning is read for unchanged pairs (none apply to this particular word sequence). Reconstructed forms use explicit advances. The full slogan is centred and uniformly reduced from a nominal 24-unit cap to approximately 23.2 units by its 275-unit width limit. Relative letter proportions are preserved; there is no independent horizontal stretch. The six-character plate has baseline 278, the seven-character layouts baseline 282, on the 600 × 300 plate plane.

Medium remains a visual weight candidate. The supplied font does not establish the precise historical cut, printer or weight; no Book/Pro font was supplied for comparison. The gallery thumbnails support construction and placement but cannot certify an exact paint contour or stroke thickness. A genuine Pro upload can replace these four reconstructed forms in a later comparison without changing the serial alphabet or artwork.

All three Wild Rose Country formats use this master. Editable serial dies, geometric/script Alberta wordmarks, red wild rose and the Moraine Lake Strong and Free motto are separate roles. Fixed slogan paths are portable in SVG and PNG exports; no proprietary font software is bundled. `provenance.json` records the source font hash, names, features, choices and limitations.

Rebuild: `python scripts/build-alberta-slogan.py /path/to/ITC-Avant-Garde-Gothic-Std-Medium.otf`, then `node scripts/build-alberta-review.mjs`. The script reads font tables; it does not execute archive contents. The review shows default and reconstructed lines at identical cap height and retains the original plate photographs alongside current renderings. Browser/export checks are run with `python scripts/verify-alberta-browser.py` after a production build and preview.
