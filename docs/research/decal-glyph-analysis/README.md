# B.C. decal letters, numbers and spacing

55 catalogue specimens inspected against the original BCpl8s photographs. These are renewal labels, not manufacture dates. The earlier typography review was a layout/candidate review; it did not identify the historical fonts.

[Portable visual report](../../../public/bc-decal-glyph-review/standalone.html) · [Full measurements](analysis.json) · [Font provenance](candidate-provenance.json)

## Method and limits

Each source text run retains its role and occurrence index, and every transcribed non-space character retains its original text index, including repeats. The report shows the actual photographic source window, actual-placement paint overlay, height-and-center shape overlays, and adjacent ink gaps in source pixels. New candidates retain native outlines and advances. Production pair spacing changes affect position only. The 1986 month is an explicitly mixed reconstruction: native Oswald Semibold J, Archivo Narrow Semibold U and Barlow Condensed Semibold L; Roboto Condensed supplies unobserved month letters. No tested single family satisfactorily matches all three observed characters.

The photograph is cropped but not perspective rectified: physical corner registration is not sufficient for precise contour claims. Placement uses the existing decal plane uniformly centered at photo crop height. Paint masks use a documented two-cluster threshold, not a production trace. Overlap scores are relative diagnostics, not font probabilities. Background colour, scan blur, scratches and perspective can change rankings. Model subpixel coordinates do not imply subpixel photographic precision.

If paint projection does not independently isolate the known number of characters, the report uses explicitly tentative equal windows and withholds font scores. Those windows and their gaps are not verified glyph measurements. Small text below 9 source pixels receives no score. The 1970 outlined digits are constructed artwork; the supplied EXPO 86 artwork is excluded from ordinary font fitting. The unreadable 1983 control is excluded from character identification.

The added candidates cover Anton Regular, Bebas Neue Regular, five Oswald weights, four Roboto Condensed weights and three Archivo Narrow weights (14 profiles), alongside existing Nimbus, Helvetica reconstruction and Barlow candidates. Source URLs, hashes, weights, native scaling and OFL notices are recorded. They are relevant comparison candidates, not asserted original printing fonts.

## Rebuild

Run `node scripts/build-decal-review.mjs` first to validate/download the original cache. Download the candidate source TTFs into a working `fonts/` directory from the URLs in `candidate-provenance.json`, verifying their SHA-256. Put deduplicated source entries in adjacent `font-sources.json`. Then run `python scripts/build-decal-glyph-candidates.py <font-cache>` and `python scripts/build-decal-glyph-analysis.py <working-directory>`. Python needs Pillow, NumPy, SciPy, fontTools and Playwright; Chromium is `/usr/bin/chromium`. Inspection regions and notes are durable inputs, not automatically accepted source contours.

## Validation

1,862 tests in 59 files and production build pass. All 572 supported decal/month renderings remain within bounds without text overlaps. Production browser checks load 879 report images, verify the embedded portable report and a 390px mobile viewport, and exercise SVG/PNG exports. The occurrence ledger contains 1,525 records, of which 497 have independently isolated paint spans and 486 receive relative font scores. Others remain explicitly tentative or too small for scoring. Run `python scripts/verify-decal-glyph-review.py` against a production preview; full results are in `validation.json`.
