# Personalized plate floral emblem

All seven B.C. personalized presets share the supplied floral emblem vector.
The tight SVG retains eight paths, its even-odd petal border and eight centre
discs. The renderer fits it uniformly into the existing dogwood placement box
and prints it white on each maker’s ocean banner. Openings stay transparent.

`supplied-emblem.svg` retains the upload; `provenance.json` identifies its hash
and placement. `src/templates/bc/floral-emblem.json` contains the same path and
circle geometry with the source viewBox. No raster or font dependency is needed
for the emblem in previews or SVG/PNG exports.
