# NWT Spectacular serial reconstruction

Source: the official NWT Gazette of May 2013, PDF page 47 / printed p. 173, containing the NWT123 plate design specimen:
https://www.justice.gov.nt.ca/fr/fichiers/gazette-des-tno/2013/05_2.pdf#page=47

This is an official plate illustration, not a photograph. Native source image is 1306 × 656 pixels; the plate outer bounds [10,6,1280,634] map to a 600 × 300 plane. No individual letter width or skew fitting is applied to the production run.

The profile reconstructs the smooth intended main-blue body of the observed N/W/T/1/2/3. Its separate pale shoulder and thin gray outline are rendered around that body. N uses a deep diagonal; W retains a sharp upper center peak and a short lower notch; 2 has a curved diagonal and square foot; 3 has unequal bowls and a projecting middle bar. Monospaced 48-unit cells and 19-unit tracking preserve the narrow painted 1 without changing the numeric run length. The remaining numeric digits are heavy condensed fallback constructions; their original contours and physical tooling remain unconfirmed.

The recommended run uses x257, baseline195.5 and cap106. The 3.5-unit outer outline and 2-unit pale outline use the same construction, with mitered joins for N/W/T. Filled observed glyphs use those widths directly; unobserved centerline glyphs use original paint stroke12 plus the extra outline width.

The deployable comparison contains six original source crops, six source overlays, the complete source plate and a whole-run overlay with adjustable opacity. Shape view matches actual source and reproduction body height and center while retaining natural width. Approximate blue-threshold overlap is diagnostic only; illustration anti-aliasing, threshold choice and thin shoulder lines prevent treating it as exact outline ground truth.

Application layout uses the shared Gazette-derived body and round cutouts, center 257 / baseline 195.5 / approximately 106-unit serial cap, dark teal ink, and a larger footer. The supplied aurora PNG is preserved byte for byte; the image is uniformly scaled to the 600 × 300 canvas and shifted down 22 units to clear the neck cutout. A second use of the same image supplies the narrow sky band above it; the SVG embeds the original image only once. This keeps the bear and trees visible inside the cutout while preserving the uploaded colours. The pale sky filter and generic surface sheen are removed for this scene. It is an approximate backdrop and differs from the original Gazette artwork. The Gazette's French “APPOSER LA VIGNETTE” instruction is treated as a placement annotation; the plate shows a blank decal well instead of permanently printing that instruction. Alternate selectable lettering and the 1986 design retain their existing renderers.
