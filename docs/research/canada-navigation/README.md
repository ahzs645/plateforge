# Canada country and federal navigation

Canada now contains a separate **Federal plates** entry alongside its thirteen provinces and territories. The region picker opens with the Canada country filter selected when the current plate is Canadian. All countries remain available from the same picker.

The federal entry exposes the two existing source reconstructions: the CANADA vehicle plate (1970 onward) and the Canadian Forces APEC 1997 variant. It reuses the original recipes and source references, while exported SVG titles and jurisdiction metadata identify Canada rather than British Columbia. Existing B.C. source/editor URLs remain valid. Provincial National Defence N designs have not been reclassified as national plates.

This navigation update does not create undocumented federal designs or claim a complete federal registration history.
