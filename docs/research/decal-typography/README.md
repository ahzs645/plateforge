# Individual decal lettering audit

Reviewed all 55 imported B.C. passenger renewal specimens individually against their credited photographs. This covers 1970–2023 and three same-year variants; 1973 and 1979 are unissued. It does not assert coverage of other classes or day-sticker variants. Renewal years are not manufacture dates.

The renderer uses per-variant line positions, cap heights, width limits, font candidates and tracking. Candidate glyphs retain their selected proportions; only whole-run uniform fitting is allowed. Existing supplied Helvetica width reconstructions remain disclosed in ../decal-review/printing-provenance.json. Additional native Barlow Condensed outline candidates are identified in printing-provenance.json. No historical font identity is certified.

The original pre-typography SVGs are frozen in public/data/decal-review/typography-before/. Every public/bc-decal-review/ card shows the original, frozen before and updated current image with individual findings. Source hashes and image resolutions are retained with the data in src/regions/canada/bc-decal-typography.json.

## Validation

`python scripts/verify-decal-typography.py` builds every selectable month for all specimens and checks transformed printed-run bounds in Chromium for clipping/collision. It covers 572 combinations; the 1984 vertical words are measured in world coordinates. These checks establish layout clearance, not a photographic font match.

`node scripts/build-decal-review.mjs` refreshes all source/current comparison records and verifies the original photographic hashes. `python scripts/build-decal-audit-printing.py` rebuilds the two additional native outline candidates from the npm Barlow fonts.

Run `npm test -- --maxWorkers=2`, `BASE_PATH=/plateforge/ npm run build`, then serve the production preview at /plateforge/ and run `scripts/verify-decal-gallery.py` and `scripts/verify-decal-review.py` to check mobile/state/export behavior.

The 1983 control remains unreadable and illustrative. Paper aging, perspective, coarse source resolution, security scoring and paint spread prevent exact historical contour or calibrated-color claims.
