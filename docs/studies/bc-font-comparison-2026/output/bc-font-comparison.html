What actually changes when we test the lettering?

The straight-sided 0 is a clear improvement. The built-in curved 7 is not the final answer. Neither commercial/free specimen is an exact replacement for the photographed B.C. lettering.

Scope of the test. Plateforge’s selected glyph formulas were transcribed into an isolated harness and rendered in four variants. Driver Gothic and Dave Hansen’s License Plate were inspected through published specimen images. This is a visual comparison, not an installed-font benchmark, pixel-overlap score, full-app run, CI result or identification of official tooling.
Loads five images directly from BCpl8s and Leeward. No font files are included.

2. Rendered geometry

Every row retains width 53, stroke 11 and tracking 8 in 100-unit cap-height coordinates. The minimal change is a zero-specific override plus the existing curved-seven branch; the global row is a diagnostic control.

7. Reproducibility and limits

11 isolated checks passed. They cover baseline path values, variant isolation, unchanged advances and strokes, rendering of all three strings, and explicit failure for unsupported inputs. These are harness checks, not visual-accuracy scores and not Plateforge’s repository tests.

The source snapshot was read from public main on 28 September 2026. Direct repository and image downloads into the execution environment failed, so this study does not claim a commit-pinned checkout or an automated photograph comparison. The harness intentionally supports only the glyphs used here.

Suggested implementation direction: keep the profile as a reconstruction; add a zero-specific stadium override, refine the seven curve against several photos, and then check P, J, A and endpoints individually. Do not replace the whole profile with either font or mark the experimental curve as an official die.
